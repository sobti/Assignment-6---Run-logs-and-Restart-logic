MinHash + LSH deduplication

Character 5-gram shingling → 128-hash MinHash signatures → LSH banding to find candidate pairs → union-find clustering, verified against the 0.8 Jaccard-similarity threshold.

Language routing

Character-count script detection, not a trained language-ID model — see the methodology note below for why, and how well it agrees with Sangraha's own labels.

PII redaction

Final in-place pass over the routed corpus: email/URL/IP/PAN/phone by regex, Aadhaar and credit-card numbers only when they pass a real checksum (Verhoeff, Luhn) — so ordinary numeric IDs of the same length aren't false-flagged.
