(ভূমগ-নিকরেন সৰ্প সমূহেন, পক্ষে কামুকবৃন্দেন আক্রান্তং ব্যান্ডং ভবতি ), অস্মাৎ (হেতোঃ, অহং) লাত ভীঃ (সঞ্ঝাতওয়া সতী ) কাত্যায়ন্যে (কাজায়নী পূজনার্সং ) কুসুম-পটলীং (পুষ্পরাশিং)ন আহরামি (ম চিনোমি)। তেন (হেতুনা অহং) পদ্ধয়া একান্তে (মির্জ্জন প্রদেশে) ত্বাং প্রপশ্না (শরণত্বেন প্রাপ্তা ) আম্ম। (ত্বং) প্রসীদ (মাং প্রতি প্রসপ্নো ভব । ততঃ ) বিষহরং বিষ সর্পবিষ-নিবারকং ) এবং মন্ত্রং দিশ (দেহি। বিষহর মিতানের কন্দর্পসর্পেন দৃষ্টানে ইতি দ্যোওয়াত ) । ১৪। (উদাহরণান্তরং প্রদায়িতি। হে) সম্বুদ্বহ! (যদুবংশ বন্ধন! শ্রীকৃষ্ণ!) ত্বং সমস্তং জনং (মিথিললোকং) অভিরক্ষিতুং (পালয়িতমের) অরন্ধ্রণীরুখনে (অরফ্লাভিঃ অনবচ্ছিনাভি স্বীকৃদ্ধিঃ লতাভিঃমনে নিবিড়ে আশ্বিন ) মনে চরসি (ভ্রমসি, কিন্তু) উরুকীর্ষিা জাং মেহাকীর্তিশার্লিনাং রাণানাং) ধুরি (অপ্রতঃ ) কীৰ্যমে (পরিগীযূমে। অতঃ) প্রসীদ (অম্লান ) করুণাং কুরু । ত্বরিতং (সম্বরং) অন ক্রমং (পসক্রসং) নির্দ্দিশ (উপদিশ ) বিস্তৃতা রা (পথভ্রষ্টঃ) বধূপনঃ এজংপ্রয়তু (প্রাপ্নোতু। ততস্থানের পদ্মা আগছেতি তাং কিয়দ্দুরমানীয় সম্প্রতি পুরোবর্তী কুটিললতাঘৃতঃপন্থা দুর্ব্বলয়া জুয়া উল্লঙ্ঘয়িত মশক্য ইতি তাং বলাদুখাপ্য স্ববক্ষমা উবাহেতি চেয়ম্ ) 11 ১৫ ।
